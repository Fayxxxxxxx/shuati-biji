# 刷题笔记 📝

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](./LICENSE)
[![Platform](https://img.shields.io/badge/platform-browser-green.svg)]()
[![Zero Dependencies](https://img.shields.io/badge/deps-0%20(除%20marked.js)-brightgreen.svg)]()

> 自带记忆曲线的本地刷题笔记 — 零安装、零注册、零后端，一个 HTML 文件搞定一切。

**自动从笔记中提取题目，按艾宾浩斯遗忘曲线定时推送复习。** 永远不需要手动制卡，写完笔记即进入复习循环。

## ✨ 功能特性

### 🔁 SRS 间隔复习（核心功能）
- 基于艾宾浩斯遗忘曲线的智能复习调度
- 自动扫描笔记中的题目卡片，无需手动录入题库
- 每日复习面板，到期的题目自动出现在顶部
- 完成复习后自动计算下次复习时间
- 复习间隔：1天 → 3天 → 7天 → 14天 → 30天 → 60天 → 已掌握
- 支持暂缓（跳过今天）、重置（重新开始复习周期）

### 📅 日记式刷题记录
- 按日期组织刷题笔记，支持 Markdown 编辑与实时预览
- 侧边栏按月归档，快速跳转任意日期
- 支持前后天切换、一键回到今天

### 📊 题目卡片系统
- 结构化录入题目信息：平台、题号、标题、难度、标签、链接
- 自动生成美观的题目卡片，支持代码高亮
- 支持描述折叠/展开、代码折叠/展开

### 🏆 勋章系统
- 连续刷题天数勋章（7天铜、30天银、100天金、365天王）
- 累计解题数量勋章（10题铜、50题银、200题金、500题钻石、1000题大师）
- 平台探索勋章（在2/3/4/5个不同平台刷题）

### 📋 模板空间
- 独立于笔记的代码模板管理
- 按 8 大算法分类整理模板
- 支持手动添加 + 自动从笔记中提取"模板"标签的题目
- 模板搜索功能

### 📂 分类浏览
- 自动将笔记中所有题目归入 8 大算法分类
- 按分类浏览题目，点击直接跳转到对应日期

### 🔍 全局搜索
- 顶部搜索栏，按题目标题或标签实时检索

### ✅ 每日签到
- 点击签到记录当天打卡
- 侧边栏底部显示签到状态和连续天数

## 🚀 使用方式

直接用浏览器打开 `index.html` 即可使用。无需安装任何东西。

所有数据存储在浏览器的 `localStorage` 中，不上传任何服务器。

## 🆚 为什么不用其他工具？

| | 刷题笔记 | Notion / 笔记软件 | Anki | LeetCode 内置 |
|---|---|---|---|---|
| 自动提取题目 | ✅ 扫描笔记 | ❌ 手动整理 | ❌ 手动制卡 | ✅ |
| SRS 间隔复习 | ✅ 自动调度 | ❌ | ✅ | ❌ |
| 多平台题目 | ✅ 蓝桥/力扣/洛谷/牛客 | ✅ | ✅ | ❌ 仅力扣 |
| 代码模板管理 | ✅ 分类 + 搜索 | ❌ 混乱 | ❌ | ❌ |
| 数据私有 | ✅ 本地存储 | ❌ 云同步 | ❌ 云同步 | ❌ |
| 零安装 | ✅ 一个 HTML | ❌ | ❌ | ❌ |

## 🛠 技术栈

- 原生 HTML/CSS/JavaScript，零依赖（除 marked.js CDN 用于 Markdown 渲染）
- localStorage 持久化存储
- IIFE 模块化架构

## ⚠️ 隐私说明

本应用所有数据均存储在本地浏览器中。请勿将包含个人笔记数据的 `localStorage` 导出文件上传到公开仓库。
