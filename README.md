# WangFly 刷题笔记 📝

纯前端单页刷题管理平台，无后端、无数据库，所有数据存储在浏览器 localStorage 中。

## ✨ 功能特性

### 📅 日记式刷题记录
- 按日期组织刷题笔记，支持 Markdown 编辑与实时预览
- 侧边栏按月归档，快速跳转任意日期
- 支持前后天切换、一键回到今天

### 📊 题目卡片系统
- 结构化录入题目信息：平台、题号、标题、难度、标签、链接
- 自动生成美观的题目卡片，支持代码高亮
- 支持描述折叠/展开、代码折叠/展开

### 🔁 SRS 间隔复习
- 基于艾宾浩斯遗忘曲线的智能复习调度
- 自动从笔记中提取题目，构建复习题库
- 每日复习面板，按到期时间排序
- 复习间隔：1天 → 3天 → 7天 → 14天 → 30天 → 60天

### 🏆 勋章系统
- 连续刷题天数勋章（7天铜、30天银、100天金、365天王）
- 累计解题数量勋章（10题铜、50题银、200题金、500题钻石、1000题大师）
- 平台探索勋章（在2/3/4/5个不同平台刷题）

### 🔍 全局搜索
- 顶部搜索栏，按题目标题或标签实时检索
- 搜索结果带日期和标签预览，点击直接跳转

### 📂 分类浏览
- 8 大算法分类：搜索、动态规划、数据结构、图论、数学/数论、字符串、贪心、其他
- 自动将题目归入对应分类
- 点击分类查看该类别下所有题目，点击题目跳转到对应日期

### 📋 模板空间
- 独立于笔记的代码模板管理
- 按分类整理模板（搜索、DP、数据结构等）
- 支持手动添加 + 自动从笔记中提取"模板"标签题目
- 模板搜索功能

### 🎯 每日练习
- 从 11~16 届蓝桥杯国赛真题中随机抽取题目
- 每日自动刷新 3-4 道练习题

### ✅ 每日签到
- 点击签到记录当天打卡
- 侧边栏底部显示签到状态

## 🚀 使用方式

直接用浏览器打开 `index.html` 即可使用。

所有数据存储在浏览器的 `localStorage` 中，不会上传到任何服务器。如需迁移数据，可使用浏览器的开发者工具导出 localStorage。

## 🛠 技术栈

- 原生 HTML/CSS/JavaScript，零依赖（除 marked.js CDN 用于 Markdown 渲染）
- localStorage 持久化存储
- IIFE 模块化架构

## ⚠️ 隐私说明

本应用所有数据均存储在本地浏览器中，不上传任何数据。如需使用此项目，请确保不将包含个人笔记数据的 `localStorage` 导出文件上传到公开仓库。
